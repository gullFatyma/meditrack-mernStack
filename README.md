## 📌 Project Overview

**MediTrack** is a full-stack clinic appointment portal developed using the MERN stack.

The application provides a secure platform where patients can register, log in, manage their appointments, and reset their passwords. Staff members have role-based access to view clinic appointments and update their status.

The project focuses on implementing **end-to-end authentication and authorization**, including JWT authentication, HttpOnly cookies, protected routes, role-based access control, and secure appointment ownership.

---

## ✨ Key Features

### 👤 Patient Features

- Patient registration
- Secure login
- Logout functionality
- Authentication persistence
- View personal appointments
- Create appointments
- Update appointments
- Delete appointments
- Password reset functionality
- Protected patient routes

### 🩺 Staff Features

- Staff-only dashboard
- View all clinic appointments
- View patient information
- Confirm appointments
- Cancel appointments
- Role-based protected routes

### 🔐 Security Features

- JWT-based authentication
- HttpOnly authentication cookies
- Password hashing with bcrypt
- Protected Express routes
- Role-based authorization
- Appointment ownership verification
- JWT expiration
- Secure password reset tokens
- Generic password-reset response
- Axios credential handling

# 🔐 Authentication Flow

MediTrack implements authentication using **JWT + HttpOnly cookies**.

The authentication flow works as follows:

```text
User Registers / Logs In
          ↓
Password verified / hashed
          ↓
JWT generated by server
          ↓
JWT stored in HttpOnly Cookie
          ↓
Browser automatically sends Cookie
          ↓
protect middleware reads JWT
          ↓
JWT is verified
          ↓
req.user = { id, role }
          ↓
Protected Route
